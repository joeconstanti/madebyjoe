Try the watch example

Open the watch demo and move the Explode slider. The parts move apart so you can see how the layers fit together. Read the watch prompt to see how the demo is specified, then use the template for a different object.

Replace [OBJECT] and [THE SMALLEST INTERESTING PART] in the template. Paste it into Claude Code in an empty folder, then open the HTML it creates.
