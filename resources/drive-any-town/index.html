Drive with WASD or the arrow keys. Use Space for the handbrake, C for the camera, N for night and R to reset.

The game sends your search to OpenStreetMap’s public geocoding service. Use public places and keep requests infrequent. Geocoding usage policy

Streets and building outlines come from map data. The game estimates walls, windows and trees. Inspired by Cherwell Valley Motor Club.
