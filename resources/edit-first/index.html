Edit first, film later

Build the edit with a stand-in voice. Record the same words, then use the Python program to move cuts, callouts, sounds and captions to the new recording.

  • Download the Python program and example files
  • Download the editing prompt

Extract the ZIP and open a terminal inside the extracted folder. Run this command with Python 3.9 or later.

python3 swap.py example/draft_edit.json example/draft_words.json example/new_words.json -o new_edit.json --words-out new_captions.json

Use example/new_words_line_missing.json in place of example/new_words.json to see how the program reports a missing line. For your own video, put swap.py, script.txt and a clips folder together, then use the prompt in Claude Code.
